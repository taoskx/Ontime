# On time 演讲者助手 · 隐私政策 / Privacy Policy

更新日期 / Updated: 2026-11-02

## 简体中文

本政策适用于 TAO LI 提供的 macOS 应用 On time 演讲者助手及其手机浏览器遥控页面。

### 数据处理
应用无需注册或登录 On time 账号。不包含广告、分析或追踪 SDK，不向开发者服务器上传个人信息、计时记录或演示文件。外观及计时偏好保存在 Mac 本机，用于恢复你的设置。

开启手机遥控后，手机与 Mac 在同一局域网中交换计时状态及控制指令。Mac 提供本地 HTTP 服务，二维码链接包含本地地址和访问令牌。连接未加密，请仅在可信网络使用，不要公开二维码。关闭遥控或重新开启服务后，请扫描新的二维码。开发者不接收这些局域网指令。

翻页功能仅向 PowerPoint 或 Keynote 发送固定演示控制指令，需要 macOS 自动化授权；不会把演示文档上传给开发者。你可以在系统设置中撤销自动化权限，关闭应用中的遥控服务以停止局域网遥控。

### 第三方与联系
Apple 负责 App Store 购买、分发及你选择向其共享的诊断信息，其处理受 Apple 隐私政策约束。访问本项目的 GitHub 支持页面受 GitHub 隐私声明约束。若你主动提交支持问题，开发者会使用你提供的信息处理该请求。GitHub Issues 是公开页面，请勿提交密码、二维码令牌、私人演示文件或其他敏感信息。

本应用不向开发者收集数据，因此不存在开发者服务器中的应用使用数据需要申请删除。你可关闭遥控、卸载应用，并按需要清理本机保留的设置。如已在 GitHub 提交信息，可通过 GitHub 管理或删除你的内容。

隐私问题请通过 [项目支持入口](https://github.com/taoskx/Ontime/issues) 联系开发者。本政策如有更新，会发布在本页。

## English

This policy covers On time Presenter Assistant for macOS and its phone-browser remote page, provided by TAO LI.

The app requires no On time account. It contains no advertising, analytics or tracking SDKs and does not upload personal information, timer history or presentation files to developer servers. Appearance and timer preferences are stored locally on your Mac.

When enabled, phone remote control exchanges timer state and commands between your phone and Mac on your local network. Your Mac hosts a local HTTP service. The QR link contains a local address and access token. Traffic is not encrypted: use a trusted network and keep the QR link private. Scan a new QR code after restarting remote control. The developer does not receive these local commands.

Slide control sends fixed presentation commands to PowerPoint or Keynote with macOS Automation permission. It does not upload presentation files to the developer. You may revoke Automation access in System Settings and disable remote control in the app.

Apple handles App Store purchases, distribution and diagnostics you choose to share with Apple under its own privacy policy. GitHub processes visits to this project's support pages under its privacy statement. If you voluntarily contact support, the developer uses the information you provide to address your request. GitHub issues are public: do not post passwords, QR tokens, private presentations or other sensitive data.

There is no developer-hosted app-usage database to delete. You can disable remote control, uninstall the app and remove locally retained settings as needed. Content you submit to GitHub can be managed through GitHub. For privacy questions, use [project support](https://github.com/taoskx/Ontime/issues). Updates to this policy will be posted here.
